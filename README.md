## 🌸 Project Overview
The **Smart Attendance System** is a console-based application developed using C++ to manage and track student attendance efficiently.  
It demonstrates real-world implementation of programming concepts like file handling, object-oriented programming, and logical decision-making.

---

## 🎯 Objectives
- Develop a structured attendance management system  
- Apply programming concepts in a practical scenario  
- Improve logical thinking and problem-solving  
- Understand data storage and retrieval  

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)  
- File Handling  
- Conditional Statements & Loops  
- Functions & Modular Design  

---

## 🤖 Computer Logic / AI Thinking
This system uses **rule-based logic**:
- Input → Process → Output  
- Condition-based decision making  
- Attendance evaluation logic  
- Prediction based on percentage  

---

## ✨ Features
- 📌 Add student records  
- 📝 Mark attendance  
- 📊 View attendance details  
- ⚡ Predict attendance eligibility  

---

## ⚙️ Working
1. User enters student details  
2. Data is stored in file  
3. Attendance is updated  
4. Percentage is calculated  
5. System predicts eligibility  

---

## 🛠️ Tech Stack
- 💻 C++  
- 📂 File Handling  
- 🧠 OOP

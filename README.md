## 🌸 Overview
A clean and simple **C++ based attendance management system** designed to track and manage student records efficiently.  
Built with a focus on clarity and practical understanding of programming concepts.

---

## ✨ Features
- 📌 Add student records  
- 📝 Mark attendance  
- 📊 View attendance data  
- ⚡ Simple console interface

- 💻 C++  
- 📂 File Handling  
- 🧠 Object-Oriented Programming
